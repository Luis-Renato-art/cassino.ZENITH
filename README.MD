Participei de um RPG que estava bem parado por falta de engajamento. Para mudar isso, criei este projeto para que os jogadores tivessem uma área extra para explorar e se divertir! 


Um dos grandes desafios era evitar que o cassino virasse uma fonte de dinheiro fácil, onde alguém pudesse alterar os resultados usando scripts maliciosos no navegador.
Por isso, em vez de fazer a matemática no código da página, o site recebe apenas o resultado final. Toda a lógica e os cálculos rodam dentro de uma planilha que utilizo como API e banco de dados.
